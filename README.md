# 🎼 Estudio Mágico

Herramienta para crear música en familia (proyecto Juegos de PF). Primero la parte de herramienta; el modo juego viene después.

- **9 instrumentos** sintetizados (sin archivos de audio, anda sin internet): teclado, guitarra (con acordes), bajo, batería + percusión (21 sonidos), arpa, armónica (soplar/aspirar), bandoneón, acordeón (con bajos) y flauta traversa.
- **Metrónomo**, velocidad (con "marcar" el tempo), compases 2/4 a 12/8, largo de 1 a 32 compases, **loop**.
- **Escalera** (diagrama de tiempo / piano roll): cada nota es un bloque; la línea va marcando qué suena y cuánto le falta.
- **Pentagrama** con notas de colores; se escribe tocando el pentagrama (♯ para sostenidos).
- **Grabar** tocando en vivo (se cuantiza), **Escribir** paso a paso desde el instrumento, deshacer/rehacer.
- Canciones guardadas solas por jugador, 4 ejemplos, exportar **WAV**, **MIDI** y copia `.json`.
- ¿Quién toca?, modo princesa 👑, modo noche, Do-Re-Mi o C-D-E, pantalla completa, teclado de la compu (fila Z… y Q…), control remoto con flechas.

Sitio estático (sin build). `pf-juego.json` lo suma al índice https://pf-juegos.vercel.app.
